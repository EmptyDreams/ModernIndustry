## 项目简介

&emsp;&emsp;现代工业（ModernIndustry for MC-1.12.2）是我很久以前就开始设想的项目，不过由于种种原因直到 2019 年才正式开工。

&emsp;&emsp;该项目是我学习 Java 时第一个开工的项目，所以项目里可能残留一些不太好的范式，但是核心逻辑已经重构了许多遍了。

## 项目现状

&emsp;&emsp;目前项目已经弃坑，除了用于测试的物品/方块样例，并没有开始进行游玩内容的开发。所以现在模组实质上是一个前置包，内部包含了多种 API 的实现，有兴趣的可以参考一下代码，可以的话点一个 star 谢谢 QAQ。

## API

&emsp;&emsp;这里简单说明一下`api`包中的各个分类的作用：

| 包名            | 作用                     | 文档                                       |
|---------------|------------------------|------------------------------------------|
| `araw`        | 实现`TileEntity`内容的自动化存储 |                                          |
| `craft`       | 独立于MC外的合成表             | [基本介绍](https://kmar.top/posts/95a18f1a/) |
| `electricity` | 电力系统                   | [工作原理](https://kmar.top/posts/1c61a114/) |
| `pipes`       | 流体管道                   |                                          |
| `graphics`    | 实现运行期自动绘制`gui`         | [在线文档](https://kmar.top/posts/e0217013/) |
| `net`         | 自动化网络通信                |                                          |
| `regedits`    | 注解式注册机                 |                                          |
| `utils`       | 模组用到的各种操作的封装           |                                          |
